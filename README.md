## 💼 Experiência e Projetos Profissionais | Professional Experience & Projects

### Companhia de Engenharia de Tráfego (CET)

Atuei com manutenção e configuração de hardware, software, redes e periféricos, além de participar do desenvolvimento de soluções voltadas à automação de processos e ao processamento de dados.

Entre os projetos desenvolvidos, destaca-se um sistema de **contagem e classificação veicular utilizando Python e visão computacional**, com OpenCV, Supervision, OpenPyXL e Tkinter, além de Roboflow para criação do dataset e um modelo YOLO pré-treinado para identificação dos veículos.

Também participei do desenvolvimento de uma solução para **extração e organização de dados de contadores de bicicletas baseados em Arduino**, realizando a leitura de informações disponibilizadas por uma página HTML via Ethernet e sua exportação para planilhas Excel.
